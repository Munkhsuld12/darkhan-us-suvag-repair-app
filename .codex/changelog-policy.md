# Changelog Policy

This project must keep `CHANGELOG.txt` as a permanent append-only change log.

Rules for future edits:
- Every file change made by Codex must add a new entry to `CHANGELOG.txt`.
- Existing changelog entries must not be deleted, rewritten, or reordered.
- Each new entry must include the date, a short title, changed files, and a clear explanation of what changed.
- Hook-generated entries may stay, but Codex must still add a human-readable summary when the change is meaningful.
- Do not log changes to `CHANGELOG.txt` itself unless the only purpose of the turn is changelog maintenance.
